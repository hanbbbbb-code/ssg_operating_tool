# 공개 자료 목록

아래 6개 파일만 공개 허용 목록에 포함합니다. 앱의 `/data/` 경로로 누구나 다운로드할 수 있다는 전제로 검토했습니다. 입력 원본과 공개 복사본의 바이트는 변경하지 않았습니다.

| 공개 파일 | 근거와 확인 |
| --- | --- |
| sales-store.xlsx | A의 01 영업 실적 복사본, 교육용 가상 160행 |
| sales-online.xlsx | A의 02 온라인 실적 복사본, 교육용 가상 160행 |
| sales-popup.xlsx | A의 03 팝업 실적 복사본, 교육용 가상 160행 |
| report-template.xlsx | A의 04 보고양식 복사본, 입력 전 빈 16열 양식 |
| event-preparation.csv | C의 08 행사준비 복사본, 72개 고유 task_id, 전 행 자료구분=가상, 사람 이름 대신 담당 역할 |
| weather-sample.json | 교육용 날씨 예제, 실제 관측·예보 아님 표시, 서울 중구 참고 좌표 |

A의 `06_데이터안내.md`는 실제 고객과 매출이 없는 교육용 가상 자료라고 명시합니다. 세 워크북의 점포는 예제A~D점, 브랜드는 가상브랜드01~10입니다. B의 `07_팝업브리프.md`는 브랜드·점포·행사 조건을 모두 가상으로 명시하며 기존 앱의 행사 문구는 이 조건을 사용합니다. 원본 폴더 A~E, 오류 입력 워크북, PDF·이미지·연습 파일·업무 원본은 Git과 전달본에 넣지 않습니다.

새로운 실제 자료를 `public/`에 복사하면 빌드 시 공개될 수 있습니다. Git 제외 규칙만으로 공개 디렉터리의 안전성을 보장할 수 없으므로 `npm run check:deploy`로 6개 목록을 확인하고, 별도 전달은 `npm run prepare:vercel`의 파일 목록을 사용합니다.
