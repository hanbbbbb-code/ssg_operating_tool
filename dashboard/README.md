# 운영 대시보드

기존 매출 비교·행사 준비·날씨 앱입니다. Vercel 배포는 [DEPLOY.md](DEPLOY.md), 공개 자료 목록은 [PUBLIC-DATA.md](PUBLIC-DATA.md)를 참고하세요. 교육용 가상 XLSX 원본의 읽기 전용 복사본을 `public/data/`에서 불러옵니다. 입력 원본과 보고 템플릿은 덮어쓰지 않습니다.

## 실행

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

내장 Browser에서 http://127.0.0.1:5174/ 를 엽니다.

```sh
npm run build
node scripts/verify-sales.mjs
```

빌드는 `dist/`, 검사 결과 및 저장 파일은 상위 `results/`에 생성됩니다.

## 매출 비교

- 원본 3개에서 열 별칭을 이름으로 맞춰 총 480행을 읽으며 원본 출처와 입력 파일·행 정보를 보존합니다.
- 점포·채널·기준주·브랜드·장르·상태와 검색 조건이 요약·점포 비교·표·보고서에 함께 적용됩니다. 페이지 이동은 표에만 영향을 줍니다.
- 파일 추가는 `원본` 시트의 12필수 열·채널·금액·날짜를 검사합니다. 오류가 있는 파일은 거부하고 기존 기록을 보존합니다. 같은 `record_id`는 다시 집계하지 않습니다.
- 메모는 `record_id`로 브라우저 로컬 저장소에 보관합니다. 현재 브라우저에만 남으며 팀 공유·서버 백업은 제공하지 않습니다.
- 보고서 저장은 `04_보고양식.xlsx`의 `보고` 시트 열 순서 16개를 유지한 새 XLSX입니다. 필터·검색에 맞는 전체 행과 메모를 저장합니다. 목표가 0이면 화면 달성률은 `—`, XLSX 달성률은 공란입니다.

## 범위

행사 준비와 날씨는 별도 탭입니다. 날씨는 서버의 OPENWEATHER_API_KEY로 실제 연결하며 미설정·실패 시 예제로 전환합니다. GitHub에 기존 앱을 올리고 Vercel에서 직접 배포할 수 있도록 설정과 안내를 포함합니다.

## 운영 탭과 날씨 서버

운영 준비 항목은 C CSV의 72개 task_id를 읽고 완료24·취소6을 제외합니다. 기준일2026-10-20에서 지연12·오늘6·2일 내 임박12·이후6·날짜 확인 필요6입니다. 담당 역할·검색·마감 분류 필터를 함께 적용합니다. 개인 확인 체크와 메모는 task_id별 localStorage에 저장하며 원본 상태를 변경하지 않습니다.

앱 폴더 `dashboard/`의 `.env.local`에 `OPENWEATHER_API_KEY=` 오른쪽으로 본인 OpenWeather 키를 직접 입력하세요. `.env.example`에는 같은 항목의 빈 값만 있습니다. 키를 넣은 뒤 Vite 서버를 재시작합니다. 키는 서버 설정에서만 읽으며 `VITE_` 환경 변수로 만들지 않습니다.

브라우저는 `/api/weather`만 호출합니다. Vite 개발·미리보기 미들웨어와 Vercel `api/weather.js`가 동일한 서버 서비스를 사용합니다. 서버는 OpenWeather 현재 날씨와 5일/3시간 예보를 병렬 조회하며 5초 제한과 10분 메모리 캐시를 사용합니다. 캐시는 서버 프로세스/서버리스 인스턴스별이며 인스턴스 재시작 시 비워집니다. 키 미설정·인증/한도/네트워크/응답/시간 제한 오류 시 D의 예제와 같은 `public/data/weather-sample.json`으로 전환하며 이유를 표시합니다. 예제 파일은 검토한 공개용 가상 자료 6개의 허용 목록에 포함해 Git과 배포본에 함께 제공합니다.

현재 위치는 서울 중구 참고 좌표(37.5636,126.9828)이며 예제A점 실제 위치가 아닙니다. 3시간 예보는 한국 현지 날짜로 첫5개 날짜를 묶어 최저·최고·최대 강수확률 및 포함 시간대 수를 표시합니다. 당일/마지막 날은 일부 시간대만 있을 수 있습니다. 예제 자료의 시각과 앱의 실제 조회 시각은 별도로 표시합니다.

Vercel에서는 Root Directory를 `dashboard`로 두고 프로젝트 환경 변수 `OPENWEATHER_API_KEY`에 키를 등록합니다. `/api/`는 SPA 재작성에서 제외됩니다. 키와 원본 데이터는 Git에 올리지 않습니다.

검사: `node scripts/verify-operations.mjs` (모의 OpenWeather 검사), `node scripts/verify-sales.mjs` (매출 회귀 검사). 실제 키가 없는 상태의 `/api/weather` 결과는 실시간 성공 증거가 아니며, `missing-key` 예제 전환 확인으로 기록합니다.

공식 응답 계약: https://openweathermap.org/api/current , https://openweathermap.org/api/forecast5

## 준비 항목 카드 보드

다섯 마감 분류는 같은 기준일·담당 역할·검색 조건을 공유합니다. 마케팅 담당만 보기 버튼은 검색어를 비우고 미완료 EV029~EV035의 7건을 모읍니다. 카드 상세의 확인 체크·메모는 이전 운영표와 같은 task_id 저장소를 사용합니다. 드래그나 개인 확인으로 원본 상태를 바꾸지 않습니다.

우천 준비 연결에서는 브리프 행사기간(2026-10-23~2026-11-01)과 예보 날짜를 교집합으로 비교하고 강수확률이 60% 이상이면 미완료 우천 준비 항목을 연결합니다. EV071은 행사 운영 담당으로, 마케팅 담당 보드와 별도의 관련 항목임을 표시합니다. 실제 서버 조회와 D 예제 선택은 출처·시각·라벨로 구분합니다. 예제 10월23일80%는 EV071 상세로 연결되며 실제 예보로 표시하지 않습니다.
